Este repositório contém as minhas soluções para os famosos [Cryptopals Crypto Challenges](https://cryptopals.com/), implementadas inteiramente em **Go (Golang)**. 

Os desafios do Cryptopals são reconhecidos na indústria por ensinar criptografia de forma prática, forçando o desenvolvedor a explorar vulnerabilidades reais e implementar ataques do zero, em vez de apenas ler sobre a teoria.

## 🎯 Objetivo do Projeto

O desenvolvimento deste repositório tem dois focos principais:
1. **Engenharia de Segurança:** Entender os mecanismos internos de esquemas criptográficos e como quebrá-los.
2. **Proficiência em Go:** Aplicar e aprofundar conceitos da linguagem, com forte ênfase em manipulação de memória de baixo nível (`[]byte`), conversão de bases, operações bit a bit (XOR) e escrita de testes unitários robustos.
